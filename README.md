# Apple-LISACom
A serial communications tool for the Apple Lisa Office System. LISACom is a native LOS desktop tool: it opens as a window on the Office System desktop, drives Serial B, dials BBSes through a WiFi modem, and moves files in both directions -- XMODEM, YMODEM with CRC-16, YMODEM batch receive, and YMODEM send with exact file sizes.
